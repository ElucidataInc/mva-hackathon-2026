# Methods

Methods reports for each track, following the organisers' [methods description template](https://huggingface.co/spaces/SageBio/rare-disease-real-kid-mva-hackathon-2026/resolve/main/static/templates/methods_description_form.xlsx).

- Reports are named `<team>_track1_report.pdf` and `<team>_track2_report.pdf` (`.md` also accepted).
- Each report states the generative AI tools used, with provider, plan or tier, and data-handling setting, as the template requires.
