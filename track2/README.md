# Track 2: Drug repurposing

Characterises the mechanism of the prioritised variants and scores approved drugs as repurposing candidates.

## Scope

- Market-approved drugs only; combinations of approved drugs are allowed.
- The report covers the variant mechanism (loss or gain of function, pathway, downstream effect) and the evidence for each candidate.

## Layout

- `scripts/`: data retrieval, evidence scoring, ranking
- `results/`: derived gene and drug tables only, no individual-level data

Commands will be added as the analysis is built.
