MVA Drug Repurposing Report

A network-proximity screen of 2,963 drug entries against the MVA gene module, run at two STRING confidence cutoffs (700 and 400). It ranks hypotheses for follow-up. It does not identify a validated treatment.

What the screen found

No drug reached significance after multiple-testing correction at either cutoff. The strongest signal is a tied block of cytotoxic and mitotic drugs, which points to a bias in the module rather than a new therapeutic direction.

Five findings

  • Nothing is statistically significant. The lowest FDR is 0.174 at STRING 700 and 0.228 at STRING 400.
  • The FDR < 0.25 "hits" are one tied block. All 17 (and all 13) sit at the permutation floor p = 1/1001, so they share a single FDR value and are ordered only by z.
  • Lowering the cutoff added no new biology. The three drugs unique to STRING 400 are gemcitabine, carboplatin and cisplatin, which are more chemotherapy.
  • The hits are oncology drugs. Across both runs the 20 unique drugs are nucleoside or platinum cytotoxics, a taxane, or mitotic and replication kinase inhibitors. Their targets (POLA1/2, PRIM1/2, CDK1/2, CDC7, AURKA/B) are heavily drugged cancer proteins.
  • One compound is a mechanistic red flag. CHEMBL5653589 binds TRIP13 and BUB3. Biallelic TRIP13 loss causes MVA, so the compound is excluded pending functional data.

Conclusion. The screen is reproducible and threshold-tested. Its current configuration recovers established oncology cytotoxics rather than an MVA-specific candidate. That is a useful negative result, especially because chemotherapy is risky in this setting (AACR 2024, PMID 39264246). Computational findings stay separate from any clinical recommendation.

The two ranked lists the report ends with are in the last tab, "Final tables".

How the screen works

Four scripts run in sequence. Each takes the previous step's files, and the final script scores every drug by how close its targets sit to the MVA module in the STRING network.

44 seed genes, patient variants, 8 manual rescue targets.

→

Pipeline from input files to the ranked workbook.

How proximity is scored

  • dc: average shortest-path distance from the drug's targets to their nearest module gene.
  • z: how many standard deviations dc is from 1,000 degree-matched random target sets. Negative means closer than chance.
  • p and FDR: empirical p with Benjamini–Hochberg correction across all drugs. With 1,000 permutations the smallest possible p is 1/1001.

How tiers and flags work

  • Tier 2: supported rescue direction, or close proximity. An inferred (auto) rescue needs phase ≥ 1.
  • Tier 3: network context only, no directional support.
  • 3-caution: inhibits a mitotic gene (AURKA/B, PLK1, BUB1B and others).
  • X-avoid/review: inhibits a loss-of-function seed, or mixed or unclear direction.
  • hard flag: mouse knockout lethality on a target, or a trial stopped for toxicity. It is a prompt to review, not proof of harm.

Limitations and next steps

Limitations

  • No drug passes FDR < 0.05 in any run, including the CDC7-excluded runs.
  • FDR < 0.25 is a permissive screening threshold, not conventional evidence.
  • 1,000 permutations create a tied block at the p floor.
  • Rankings agree only moderately across cutoffs (Spearman 0.4984).
  • The module is dominated by proteins oncology has drugged for decades, so proximity partly measures that.
  • Drug-target sources mix binding, mechanism, literature, inferred and network-context links.
  • 20 of 44 seeds are isolated at STRING 700 and 4 are unmapped; the 400 coverage is unverified.
  • Evidence queries had gaps: capped trial counts, text-matched termination reasons, incomplete FAERS. The workbook's safety_review_flag is true for 2,584 of 2,963 rows, so it does not discriminate between drugs.

Next steps

  • Review CDC7 read-level evidence (strand, mapping quality, allele balance) and keep both run versions.
  • Run a seed-set sensitivity analysis without GNRHR if it is classified as a secondary finding.
  • Rebuild the seed report at STRING 400 to measure real coverage.
  • Rerun with more permutations to break the tied block.
  • Check compound identity and evidence type for each retained drug–target link (for example Compound 8, PMID 17480064).
  • Build the mechanism-evidence table for niacin, gentamicin and the mTOR drugs.
  • Test any retained compound in an MVA-relevant cell model before any further claim.

Reference: Yost et al. 2017, PMID 28553959 (biallelic TRIP13 loss and MVA). This supports TRIP13 relevance and does not show that CHEMBL5653589 inhibits TRIP13.
